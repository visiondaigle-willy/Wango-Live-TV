Installer, pas à pas

  1. Ouvrez le fichier téléchargé.Il se trouve en général dans le dossier « Téléchargements ».
  2. Si Windows affiche « Windows a protégé votre ordinateur »cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Ce message apparaît tant que l’installateur n’est pas signé numériquement ; la signature est prévue.
  3. Suivez l’installation.Wango-Live-TV s’installe dans les Programmes de Windows, comme un logiciel classique. Restez connecté à Internet : l’installation télécharge NDI, utile pour envoyer l’image par le réseau, s’il n’est pas déjà présent.
  4. Lancez Wango-Live-TV et créez votre premier projet.Un projet correspond à un culte et tient dans un seul dossier.
  5. Faites le test de l’ordinateur.Préférences → Tester ce PC : trois minutes pour savoir ce que votre ordinateur peut faire.

Les mises à jour

Les nouvelles versions sont publiées sur cette page, avec leurs nouveautés. Bientôt, Wango-Live-TV vous signalera lui-même qu’une nouvelle version existe, avec un lien vers cette page ; rien ne s’installera sans vous.

Besoin d’aide ?

Dans Wango-Live-TV, la touche F1 ouvre l’aide intégrée. Le manuel et les questions fréquentes répondent aussi à la plupart des questions. Sinon, écrivez-nous.
